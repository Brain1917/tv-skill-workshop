# Начать практику · мастерская скиллов для телевидения

Команда открывает настроенный проект, пишет «Начать практику» и получает помощника на всё занятие. Он проводит интервью, собирает командный скилл в ZIP и помогает коллеге испытать именно этот архив. За разговор отвечает `tv-workshop`, за создание и упаковку файлов отвечает `tv-skill-builder`.

[Скачать комплект для прогона](https://github.com/Brain1917/tv-skill-workshop/releases/download/v0.2.0-rc.4/tv-workshop.zip) · [Все выпуски и изменения](https://github.com/Brain1917/tv-skill-workshop/releases)

## Установить на ноутбук

1. Скачайте **tv-workshop.zip** со страницы нужного выпуска GitHub и распакуйте его. На прогоне используйте выпуск, указанный организатором. [Основной выпуск для установки](https://github.com/Brain1917/tv-skill-workshop/releases/latest)
2. Откройте распакованную папку **TV-Workshop**. Скопируйте файл **Начать практику.md** в корень того проекта, где на ноутбуке уже работает модель. Из комплекта скопируйте обе папки скиллов с их содержимым в `.opencode/skills/` этого проекта. При необходимости создайте эту директорию. Другие файлы проекта сохраняются. На macOS скрытые папки в Finder показывает сочетание Cmd + Shift + точка. В Windows выберите «Вид → Показать → Скрытые элементы».
3. Скопируйте также `AGENTS.md` в корень проекта. Если там уже есть свой `AGENTS.md`, добавьте в него две инструкции из комплекта. Откройте этот проект в OpenCode в режиме с правом работы с файлами и запуска команд. В новом чате напишите **Привет**. При успешной проверке помощник ответит: **Всё установлено, можно использовать для воркшопа.** Если ответ не появился, проверьте выбранную модель. Для проверочного проекта на втором ноутбуке организаторы также настраивают доступ к модели.
4. Откройте [Начать практику](Начать%20практику.md) и проверьте первый запрос. Команда общается с одним помощником. Учебные примеры и правила ясного текста уже входят в комплект. Командные архивы и карточки появятся в папке **Готовые скиллы** внутри проекта.

## Проверить и обновить установленную версию

По фразе «Начать практику» помощник сначала читает свой VERSION и проверяет доступный выпуск на GitHub. У основной установки он проверяет основной выпуск. У копии для прогона учитывает и версии с пометкой rc. Если найдено обновление, покажет ссылку и попросит организатора его установить. Если GitHub API недоступен, помощник сверит теги по ленте выпусков и проверит наличие ZIP. Если оба способа недоступны, он укажет причину. Занятие можно продолжить с локальной копией.

В выпусках 0.1.0 и 0.2.0-rc.1 встроенной проверки ещё нет. При первом переходе организатор один раз устанавливает новый комплект вручную. Старую памятку «Начать здесь.md» можно убрать из рабочей папки, чтобы на старте было видно одно название.

Постоянная [ссылка на ZIP](https://github.com/Brain1917/tv-skill-workshop/releases/latest/download/tv-workshop.zip) ведёт к последней основной версии. Пробный выпуск для прогона скачивают отдельно. Чтобы обновить рабочее место, закройте проект, замените файл «Начать практику.md» и две папки скиллов и обновите инструкции в `AGENTS.md` по шагу 3. Откройте тот же проект и начните новый чат. Для одинаковой версии на всех ноутбуках используйте один скачанный архив.

При подготовке следующего выпуска укажите его тег в [.opencode/skills/tv-workshop/VERSION](.opencode/skills/tv-workshop/VERSION), соберите архив из этого коммита и приложите его к выпуску под именем `tv-workshop.zip`.

## Прогон организаторов

1. На первом ноутбуке попросите новичка начать без идеи и своего файла. Замерьте время от первой реплики до ZIP. Убедитесь, что помощник предложил одну задачу и сам показал готовый архив.
2. Передайте именно ZIP на второй ноутбук. Коллега открывает чистый проверочный проект, устанавливает скилл из архива и следует его README. Запишите полученный результат, критерий и время до первого успешного теста.
3. Назовите одну конкретную ошибку. Помощник исправляет правило и пересобирает архив. На втором месте повторите тест с обновлённым ZIP. Проверьте также в новом чате случай с собственным разрешённым материалом и вопрос об ИИ посреди работы. [Три учебных прохода](.opencode/skills/tv-workshop/references/practice.md)
4. Откройте «Начать практику.md» без запущенной модели. Прочтите путь восстановления. Проверьте открытие карточки посетителем, когда организаторы выдадут адрес. До этого архив и карточку можно сохранить локально.
5. Перед массовой установкой подтвердите, какой выпуск испытали, сколько заняли интервью и сборка, смог ли коллега запустить ZIP и что осталось исправить. Ориентир программы: закончить проверку команды к 14:25 и использовать следующие десять минут для публикации.

## Во время практики

- Для первого запуска достаточно OpenCode, доступа к модели и права записи в папку проекта. Подключение к модели организаторы настраивают отдельно.
- Готовый командный ZIP загружает участник на сайт, адрес которого даёт ведущий. Пока адреса нет, помощник сохраняет архив и текст карточки.
- После практики другой человек может скачать командный скилл, прочитать его инструкцию и запустить со своим доступом к совместимой модели.

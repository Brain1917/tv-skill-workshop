# Мастерская скиллов для телевидения

Комплект для практики в OpenCode. Одна команда выбирает задачу редакции, создаёт скилл, испытывает его на примере и готовит ZIP для коллег. В проекте установлены помощник диалога `tv-workshop` и конструктор файлов `tv-skill-builder`.

## Установить на ноутбук

1. [Скачайте установочный ZIP](https://github.com/Brain1917/tv-skill-workshop/releases/latest/download/tv-workshop.zip) и полностью распакуйте его в папку, где участники смогут создавать файлы.
2. В OpenCode откройте папку **TV-Workshop**. Внутри неё лежат этот README и служебная папка `.opencode`. Если распаковщик создал ещё одну папку сверху, выберите внутреннюю **TV-Workshop**.
3. Выберите подключённую организаторами модель с поддержкой инструментов. В новом чате напишите: **«Используй tv-workshop. Начать воркшоп»**.
4. Проверьте начало практики: помощник предлагает создать свой скилл или проверить чужой. Для проверки всего комплекта выберите создание, назовите одну задачу и дождитесь пути к созданному `SKILL.md`. Откройте новый чат в этом проекте и проверьте созданный скилл на примере команды.

Если на ноутбуке уже есть настроенный проект с доступом к модели, сохраните его настройки. Из распакованного проекта скопируйте в его `.opencode/skills/` только две папки: `tv-workshop` и `tv-skill-builder`. Откройте этот проект заново и начните с шага 3. На macOS скрытые папки можно показать в Finder сочетанием Cmd + Shift + точка. В Windows используйте «Вид → Показать → Скрытые элементы».

## Поставить обновление

Одна и та же ссылка на ZIP ведёт к последнему выпуску. Номер и описание изменений видны на [странице выпуска](https://github.com/Brain1917/tv-skill-workshop/releases/latest). На уже настроенном ноутбуке скачайте новый выпуск в отдельную папку. Закройте учебный проект, замените в нём только папки `tv-workshop` и `tv-skill-builder`, откройте проект и начните новый чат. Работы команд лежат в отдельных папках. Для одинаковой версии на всех ноутбуках используйте один скачанный архив.

## Во время практики

- Для первого запуска достаточно OpenCode, доступа к модели и права записи в папку проекта. Подключение к модели организаторы настраивают отдельно.
- Готовый командный ZIP загружает участник на сайт, адрес которого даёт ведущий. Пока адреса нет, помощник сохраняет архив и текст карточки.
- После практики другой человек может скачать командный скилл, прочитать его инструкцию и запустить со своим доступом к совместимой модели.

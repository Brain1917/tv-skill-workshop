# Воркшоп для телеканалов

В новом чате проекта перед первым ответом один раз выполни из корня проекта `python3 -B .opencode/skills/tv-workshop/scripts/check_version.py --status` (в Windows с Python Launcher — `py -3 -B` вместо `python3 -B`). Команда подготавливает локальный скилл. Выполняй её без вводной реплики, установку и проверку версий с участником не обсуждай. Если команда не запустилась или просит технической помощи, предложи позвать помощника к столу.

Затем загрузи `tv-workshop` инструментом `skill` и прочитай текущий `.opencode/skills/tv-workshop/SKILL.md` с диска. Применяй содержимое файла после подготовки, даже если в описании ранее загруженного скилла был другой текст. На отдельное «Привет» передай только статус команды. На «Начать практику» начни занятие сразу. В остальных случаях ответь по задаче. В этом чате повторно готовить скилл не нужно.

# Воркшоп для телеканалов

В новом чате этого учебного проекта сначала загрузи скилл `tv-workshop` инструментом `skill`. Первую строку каждой реплики пользователю бери из раздела «Первая строка ответа» загруженного скилла, в том числе при последующих вопросах.

Если первое сообщение — только «Привет» (регистр и знаки в конце могут отличаться), выполни раздел «Проверка установки» и после первой строки передай только полученный статус.

По команде «Начать практику» или «Начать воркшоп» загрузи тот же скилл и начни занятие, даже если перед этим проверяли установку.

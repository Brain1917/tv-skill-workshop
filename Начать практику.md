# Начать практику

**Организатору.** Откройте распакованную папку в OpenCode и напишите в новом чате **Привет**. Ответ при успешной проверке: **Всё установлено, можно использовать для воркшопа.**

1. **Как начать.** Откройте в OpenCode ту папку, в которой организаторы настроили модель. В новом чате напишите **«Начать практику»**. Если получили общую справку, введите **«@tv-workshop Начать практику»** и выберите помощник из подсказки.
2. **Как проверить версию.** Перед первым вопросом помощник сверит установленный выпуск с GitHub. Если доступно обновление, покажет ссылку. Попросите организатора установить его и откройте новый чат. Если GitHub недоступен, можно продолжить с локальной копией. Для ручной сверки откройте [номер установленной версии](.opencode/skills/tv-workshop/VERSION) и [выпуски на GitHub](https://github.com/Brain1917/tv-skill-workshop/releases). Метка `rc` означает версию для прогона, `Latest` указывает основной выпуск.
3. **Если чат не отвечает.** Посмотрите вверху чата, выбрана ли модель, указанная организаторами. Если после выбора ответа всё ещё нет, **останьтесь за ноутбуком, покажите номер стола и позовите технического помощника**. Ключ доступа вводит организатор.

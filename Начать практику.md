# Начать практику

**Организатору.** Откройте распакованную папку в OpenCode и напишите в новом чате **Привет**. При готовой установке появится статус: **Всё установлено, можно использовать для воркшопа.**

1. **Как начать.** Откройте в OpenCode ту папку, в которой организаторы настроили модель. В новом чате напишите **«Начать практику»**. Если получили общую справку, введите **«@tv-workshop Начать практику»** и выберите помощник из подсказки.
2. **Что происходит при входе.** Помощник сам подготовит скилл и ответит. Если GitHub недоступен, можно заниматься с установленной копией.
3. **Если чат не отвечает.** Посмотрите вверху чата, выбрана ли модель, указанная организаторами. Если после выбора ответа всё ещё нет, **останьтесь за ноутбуком, покажите номер стола и позовите технического помощника**. Ключ доступа вводит организатор.
